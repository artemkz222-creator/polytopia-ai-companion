# Polytopia AI Companion

Помощник по The Battle of Polytopia с анализом скриншотов с помощью ИИ.

## Что уже работает
- Адаптивный интерфейс для мобильного браузера.
- Загрузка PNG, JPEG и WebP до 15 МБ.
- Предпросмотр загруженного скриншота.
- Локальная история последних восьми снимков.
- Анализ изображения моделью со зрением: краткая оценка позиции, экономика, угрозы, лучший следующий ход и план на три хода.
- Необязательный комментарий с племенем, технологиями и целью игрока.
- Индикация загрузки, отмена запроса, повторная попытка и сообщения об ошибках.
- Отдельное указание неопределённости: нечитаемые значения не должны подаваться как установленные факты.

## Запуск
Требуется Node.js 24 или новее и привязка проекта к Netlify.

```bash
nvm use 24          # версия указана в .nvmrc
npm install
npm test            # серверные и клиентские тесты
npm run typecheck   # проверка типов
npx netlify link    # один раз: привязка к сайту на Netlify
npx netlify dev --port 8889
```

`npm run dev` запускает только интерфейс: без Netlify Dev запрос `/api/analyze` вернёт 404, и сайт подскажет нужную команду.

Для локального запуска серверной части нужен именно Node.js 24: на более старых версиях Netlify Dev отдаёт интерфейс, но `/api/analyze` отвечает ошибкой 500.

Netlify AI Gateway включается только после первого успешного продакшен-деплоя сайта, и на аккаунте должны быть кредиты. До этого анализ возвращает сообщение «ИИ для этого сайта ещё не активирован».

Откройте http://localhost:8889. Netlify Dev запускает Vite и серверный обработчик `/api/analyze`. Для работы только над интерфейсом можно использовать `npm run dev`.

## Анализ
Кнопка «Разобрать с ИИ» отправляет изображение и комментарий на Netlify Server. Крупные изображения предварительно уменьшаются в браузере до 1920 пикселей по длинной стороне. Сервер проверяет размер, тип и сигнатуру файла, затем обращается к `gpt-4.1-mini` через Netlify AI Gateway с помощью официального SDK OpenAI. Учётные данные предоставляются платформой на сервере; ключи не передаются в браузер.

Ответ передаётся потоком NDJSON: события `status` поддерживают соединение, затем приходит `result` или `error`. Это позволяет дождаться распознавания изображения без тайм-аута первого ответа сервера. Результат проверяется на сервере перед показом. Анализ сам по себе не сохраняет изображение или рекомендации в постоянное хранилище приложения.

ИИ видит только приложенный кадр и комментарий. Он может ошибаться в распознавании объектов и правилах игры. Проверяйте советы по реальной доступности действий; точность стратегии следует оценивать на скриншотах разных племён и стадий партии.

## Проверки
`npm test` проверяет ограничения загрузки, передачу изображения модели, структуру результата, отмену, ошибки и поток ответа без обращения к платному API. `npx tsc --noEmit` проверяет типы интерфейса.
