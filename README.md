# Polytopia AI Companion

Первая версия интерфейса для помощника по The Battle of Polytopia.

## Что уже работает
- Адаптивный интерфейс для мобильного браузера.
- Загрузка PNG, JPEG и WebP до 15 МБ.
- Предпросмотр загруженного скриншота.
- Локальная история последних восьми снимков.
- Явная индикация, что AI-анализатор ещё не подключён.

## Запуск
Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

## Важно
Это пока frontend-MVP. Он не распознаёт юниты, города, ресурсы и технологии и не выдаёт стратегические рекомендации. Для настоящего анализа нужен серверный backend с подключённой моделью зрения. API-ключ нельзя помещать во frontend или коммитить в GitHub.
